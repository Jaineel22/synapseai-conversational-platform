# SynapseAI — Frontend

React 19 + Vite single-page app for SynapseAI. For the full project overview, architecture, API reference, and setup instructions, see the [root README](../README.md).

## Quick reference

```bash
npm install
npm run dev      # http://localhost:5173 — proxies /api to localhost:8080 (see vite.config.js)
npm test
npm run lint
npm run build
```
